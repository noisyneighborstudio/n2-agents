# Vendor icons

Monochrome marks shown beside each lab in the Setup Assistant, rendered as
template images so they take the label colour.

- `claude`, `codex` (OpenAI), `grok`, `cursor`, `opencode`, `hermes` (Nous
  Research): from [lobe-icons](https://github.com/lobehub/lobe-icons), MIT.
- `gemini`: from [simple-icons](https://simpleicons.org), CC0.

Each file is normalised to a fixed `24×24` viewport with a black fill so that
CoreSVG renders it. The marks remain trademarks of their owners; they are used
here only to identify the vendor's CLI.
